# Joe's Gematria Lab
Gematria calculator, date numerology, holiday presets, a connect-the-dots matcher and a number tracker. Static site, no backend; tracker data stays in the browser (localStorage) with CSV export/import. Number patterns for research only.
Ciphers match gematrix.org / Gematrinator conventions. Run `node test.js` to check the math.
Built by Ace Apps.
